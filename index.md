# CEMRG Lab Guides

Onboarding and reference for the CEMRG research group.

## Where to start

- **New lab member?** Start with [New machine setup](docs/new-machine/) to bring a fresh Ubuntu box up to working condition, then move on to [Development tools](docs/dev-tools/) for the lab's research software.
- **Need to log in to an Imperial machine?** See [Imperial / OPKSSH login](docs/imperial/opkssh-login.html).
- **Sysadmin tasks** (creating users on shared lab machines) live under [Sysadmin](docs/sysadmin/).

## Conventions

- Recipes are written for Ubuntu (the lab default). macOS-only notes are flagged inline.
- Anything with `sudo` assumes you have admin rights on the target machine; ask before running on shared boxes.
- If a command here fails, fix it and open a PR — the goal is that everything on this site actually works.
