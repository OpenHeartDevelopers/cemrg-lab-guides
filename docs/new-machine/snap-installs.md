# Install from `snap`

## VSCode
```shell
# VSCode
sudo snap install code --classic
```
Once installed, loging with your github account to transfer settings over to different machines. 


## Slack
``` shell
# Slack 
sudo snap install slack
```
Don't forget to log into Slack.
