# New machine setup

End-to-end recipe for taking a fresh Ubuntu install to a working lab machine. Run the pages in order:

1. [Web installs](web-installs.html) — GitHub SSH key, Starship, Conda, Dropbox, browser, Kitty.
2. [apt installs](apt-installs.html) — system packages.
3. [Rust utils](rust-utils.html) — modern replacements for `ls`/`grep`/`find`/`cat`.
4. [Snap installs](snap-installs.html) — VSCode, Slack.
5. [Dotfiles](dotfiles.html) — clone `myconfig` and wire everything up.
6. [Nvidia driver fix](nvidia.html) — only if you boot into nouveau.

When you're done here, move on to [Development tools](../dev-tools/).
