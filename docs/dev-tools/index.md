# Development tools

Lab-specific research software. Before installing anything here, make sure you have `~/dev` and `~/installs` directories:

```shell
mkdir -p ~/dev/{build,python,src} ~/installs
```

Then pick what you need:

- [cemrg-heartbuilder](cemrg-heartbuilder.html)
- [imatools](imatools.html)
- [meshtool](meshtool.html)
- [ITK-SNAP and c3d](itk-snap.html)
- [Paraview](paraview.html)
- [Meshalyzer](meshalyzer.html)
- [CemrgApp](cemrgapp.html)
- [Docker](docker.html)
